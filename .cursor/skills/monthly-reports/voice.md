# Voice — client monthly report

Audience: Trafigura Foundation staff forwarding a PDF internally. Not SEO specialists.

## Tone

- Plain language, short paragraphs, British English (prioritise, behaviour, organisation).
- Decision-ready: what happened, why it matters, what we do next.
- Honest. Never write “strong improvement” next to a declining KPI. Seasonal dips are fine to name.
- One insight per data section, titled **What this means**. Explain the metric once, then interpret.
- ~6–8 pages. Cut device/country tables, Semrush, and generic SEO objectives.

## Jargon → client labels

| Internal | Client table / prose |
|---|---|
| Clicks | Clicks from Google |
| Impressions | Times shown in search |
| CTR | Click-through rate (then CTR is OK) |
| Avg. position | Average position (lower = better → “Improved”) |
| Sessions | Total visits (sessions) |
| Organic sessions | Visits from Google search |
| Engagement rate | Engagement rate |
| LCP | Time to main content |
| CWV / Lighthouse | Site speed / lab test |
| AEO | Answer engines & AI visibility |

Brand queries ≈ contain “trafigura” (incl. “fondation trafigura”). Non-brand is the long-term discovery lever — say that in prose, don’t lecture.

## Insight pattern

1. Translate the movement in one sentence (MoM).
2. Add YoY if it changes the story (e.g. MoM down, YoY flat).
3. Tie to a cause only when evidenced: content publish, seasonality, technical ship, outage. If unknown, say seasonal / mix — don’t invent a ranking penalty.

Example (good): fewer impressions in August, but people who saw the site clicked more; YoY clicks flat — not a technical regression.

Example (bad): “Excellent SEO progress this month” above −40% clicks.

## Position & deltas

- HTML: `<span class="positive">`, `negative`, `neutral`.
- Unicode minus: `−5.1%`.
- Position dropped from 8.9 → 8.3 → **Improved** (green), never “−6.7%” in red.
- Flat (~±1%): `Stable` / `neutral`.

## Recurring facts (don’t contradict)

- Site: https://trafigurafoundation.org/
- Public hubs: `/content-hub/` · `/partners-stories/` · `/areas-of-work/`
- Pillars: Sustainable Livelihoods, Prepared Communities, Thriving Nature
- Prepared by UNE. Cover/thanks: “Made By UNE”
- AEO = accurate citation of who they are, what they fund, three pillars — not ChatGPT referral volume
- Search is brand-led; homepage usually ~half of GSC clicks

## Do not put in the client PDF

- Looker Studio URL
- “Items needing your input” / internal todos (use `YYYY-MM-todos.md`)
- Raw GSC query CTR/position tables unless they help the story (client “Top searches” = term, clicks, one-line “what it tells us”)
- Theme/file paths, ticket IDs, git hashes
